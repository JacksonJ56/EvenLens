## 验证范围

这验证了当前源码在同一台机器的隔离安装环境中可按文档启动，不等于在所有操作系统和网络环境都已验收。没有独立验证 Windows 原生安装或首次拉取 RSSHub 容器。

AI 功能仍需要读者配置自己的模型和搜索权限；在线评论采集还需要独立 MediaCrawler、适用授权及本人平台会话。此次没有把 AI 研究或在线采集记作首次运行成功。榜单条目数属于当次观察，可能随上游更新而变化。
